# Exact UI — what I know (as of 13 Nov 2026; verify against the checkout, it moves weekly)

- Exact = Contract (`app.contract`: view/state/actions/resources/mutations/derive) + data module (`app.ts`, TypeScript on Hermes; grants for net/files/sqlite/secrets; **cannot import npm package code**, only types — MogCore's TS port must be dependency-free, which it is) + `app.json` manifest + optional `app.tamber` brand tokens + `modules/apple/*.swift` native modules and native views.
- Native views (`docs/recipes/native-views.md`): a hyphenated tag (`mog-capture`) declared in `app.json` `modules`, backed by an `ExactModule` with `ExactNativeFactory`; props are strings; events `message/press/change/load`; time via `context.frames`/`context.after` (never timers, so `clock` works); `intrinsicSize`. "A view needing a platform API (a map, the camera) is a Swift view." Runtime-level camera access is out for v1; a Swift view owning ARKit is the documented path.
- Native modules (`docs/recipes/native-module.md`): `app.ts` calls `native.call({op:…})` / `native.later`; resources that read native can be kept across launches.
- Batteries: `@exact/purchases` (store on iOS/macOS/Android — `getDetails`, `listPurchases`, `unfinishedPurchases`, `purchase`), `@exact/sign-in` (Apple/Google, provider's own button, ID token to your server), `permissions` recipe (one grant line + purpose string; Exact never answers the platform prompt), `theme` (`app.tamber` with `light-dark()` tokens and `scheme=fixed`), `tabs`, `navigation-stack`, `grouped-form`, `persisted-setting`, `numeric-readout`, `motion`, `eas-ios`, `purchases`, `content-design` parts (`SummaryCard`, `RingProgress`, `StatBar`, `Badge`, `DoneMark`, `EmptyState`, `RoundButton`).
- Agent loop: `exact new`, `pattern <name>`, `ios --prebuild` (10–15 min first build), `contract build app.contract --json --errors-only` (CI gate), `verify ios`, `agent ios --touch platform`, `share` (AppDrop link), `smoke.mjs`. Ten agent ops: tree · screenshot · tap · type · state · layout · logs · clock · prefer · perf.
- Philosophy constraints that collide with our design system: controls, bars, type and dark mode are the platform's; emphasis is a *part*, not paint on a control; "leave the rest unsaid". Our chunky lipped buttons and custom type are therefore *tells*. Brand survives through `app.tamber` tokens (paper, accent #2E5BFF, positive, flame amber, finish gold) and content parts; custom fonts are an open question (spike).
- Source checkout required (no packaged CLI). Prereqs: Rust, Bun 1.4.2, Chrome, Xcode.
