# PlanCard

A single recommendation, always tied to the finding that produced it. The "why this" row is the product's core value proposition — generic advice is the most common complaint about every competitor.

## Anatomy

Impact rank numeral in `ink-300` · action headline (`title-3`) · body (`body`) · a "why this" row linking to the triggering finding, with the metric name and value in `accent` and tappable through to its overlay · metadata row of timeline and effort chips · evidence badge.

## Variants

- **action** — safety tiers 1–2, in the main ranked plan. Things the user can safely do alone.
- **professional** — safety tiers 3–4. Visually distinct: a 3px dashed `line-200` left border, no rank numeral, sitting below a divider in its own section. Never confused with something to act on alone.

## Rules

- Every card shows its triggering finding. A card that cannot name its evidence does not ship.
- Tier 3 and 4 items never enter the ranked list. The plan the user acts on alone contains only things they can safely do alone.
- Never a dose, never a caloric target, never a goal weight. Rate guidance only, phrased as a range.
- The professional-referral line always carries the no-financial-relationship sentence. It is a trust asset worth keeping even when affiliate revenue becomes available.

## Never rendered, at any tier

Bone smashing, mewing as a structural fix, steroids, SARMs, unregulated peptides, leg lengthening, or any recommendation framed as comparison against another person. These are denied in code, not by design convention.
