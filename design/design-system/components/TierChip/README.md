# TierChip

The PSL tier label, derived from the percentile — not a separate judgement.

`label` type, `radius-sm`, 1px `line-200` border, `ink-700` text, transparent fill.

## Rules

- **Never colored by tier.** A Chadlite chip and an LTN chip are visually identical. Coloring the tier reintroduces the score-quality ramp the system exists to avoid.
- Never accompanied by an icon, never all-caps on the expanded name.
- Tapping opens an explainer sheet defining the tier as a percentile against the reference distribution — never as a comparison against other users.

## Copy

Chip reads `HTN`. Subline reads "High-tier normie · roughly the 68th percentile of our reference distribution." Never "better than 68% of guys."
